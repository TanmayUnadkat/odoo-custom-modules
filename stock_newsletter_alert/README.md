# Stock Newsletter Alert

## 📌 What it does
Sends automatic email notifications to newsletter subscribers when:
- 📉 Product stock falls **below a set threshold**
- 📈 Product stock is **replenished**

## ⚙️ Installation
1. Copy module to your Odoo addons folder
2. Update apps list
3. Install **Stock Newsletter Alert**

## 🔧 Configuration
- Set threshold quantity on each product
- Subscribers must opt-in to newsletter

## 💻 Tech Used
- Python (models, automated actions)
- XML (views)
- QWeb (email template design)
- Data (mailing list template)
