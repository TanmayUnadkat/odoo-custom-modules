## 📦 Modules

### 1. stock_newsletter_alert
- **Description:** Automatically sends email notifications to newsletter subscribers 
  when a product's stock quantity falls below a defined threshold and again 
  when the stock is replenished.
- **Odoo Version:** 19
- **Tech Used:** Python, XML, QWeb, Email Templates

## 🛠️ Tech Stack

- PostgreSQL
- Email / SMTP Integration
